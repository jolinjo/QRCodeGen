# 快速安裝指南

## 步驟 1：準備擴充功能檔案

確保您已經下載或克隆了整個 `chrome-extension` 資料夾。

## 步驟 2：打開 Chrome 擴充功能管理頁面

1. 打開 Google Chrome 瀏覽器
2. 在地址欄輸入：`chrome://extensions/`
3. 按 Enter 鍵

## 步驟 3：啟用開發人員模式

1. 在擴充功能頁面的右上角，找到「開發人員模式」開關
2. 將開關切換到「開啟」狀態

## 步驟 4：載入擴充功能

1. 點擊「載入未封裝項目」按鈕（Load unpacked）
2. 在檔案選擇對話框中，瀏覽到 `chrome-extension` 資料夾
3. 選擇該資料夾並點擊「選擇」或「開啟」

## 步驟 5：確認安裝

1. 擴充功能應該會出現在擴充功能列表中
2. 您應該會看到「QR 碼產生器」擴充功能
3. 確保擴充功能是「啟用」狀態（開關是開啟的）

## 步驟 6：使用擴充功能

1. 點擊 Chrome 工具列右上角的擴充功能圖標（拼圖圖示）。
2. 找到「QR 碼產生器」並點擊，擴充功能會在新分頁開啟完整介面。
3. 也可以將擴充功能圖示固定在工具列上，之後直接點擊即可開啟 QR 碼頁面。

## 疑難排解

### 問題：找不到擴充功能圖標

**解決方案：**
1. 點擊 Chrome 工具列右上角的擴充功能圖標（拼圖圖標）
2. 找到「QR 碼產生器」
3. 點擊圖釘圖標將擴充功能固定到工具列

### 問題：擴充功能無法載入

**解決方案：**
1. 檢查 `chrome-extension` 資料夾是否包含所有必要檔案：
   - manifest.json
   - background.js
   - page.html / page.css / page.js
   - icons/ 資料夾（icon16.png, icon48.png, icon128.png）
2. 檢查 Chrome 擴充功能頁面是否有錯誤訊息
3. 點擊「重新載入」按鈕重試

### 問題：API 請求失敗

**解決方案：**
1. 檢查網路連接
2. 檢查 API 是否正常運作：https://api.qrcode-monkey.com
3. 查看瀏覽器 Console 的錯誤訊息（按 F12 打開開發者工具）
4. 如果 API 需要 API Key，請在 `popup.js` 中添加相應的 headers

### 問題：圖標顯示不正常

**解決方案：**
1. 確認 `icons/` 資料夾中包含所有圖標檔案
2. 如果圖標檔案缺失，執行 `python3 create_icons.py` 重新生成
3. 或者在 `manifest.json` 中檢查圖標路徑是否正確

## 更新擴充功能

當您修改了擴充功能的程式碼後：

1. 打開 `chrome://extensions/`
2. 找到「QR 碼產生器」擴充功能
3. 點擊「重新載入」圖標（🔄）
4. 擴充功能會使用最新的程式碼

## 卸載擴充功能

1. 打開 `chrome://extensions/`
2. 找到「QR 碼產生器」擴充功能
3. 點擊「移除」按鈕
4. 確認移除

## 需要幫助？

如果遇到其他問題，請檢查：
- Chrome 瀏覽器是否為最新版本
- 是否有其他擴充功能衝突
- 瀏覽器 Console 的錯誤訊息（F12 > Console）
